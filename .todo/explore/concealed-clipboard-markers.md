# Concealed Clipboard Marker Detection

## Summary

Extend the clipboard kit to detect concealed/transient clipboard content using platform-specific markers. This is the most reliable way password managers signal "don't capture this" — more reliable than excluded apps lists or secret heuristics.

## Context

Password managers and other security-sensitive apps mark clipboard content with special flags:

- **macOS:** `NSPasteboard` types `org.nspasteboard.ConcealedType` and `org.nspasteboard.AutoGeneratedType`
- **Windows:** `ExcludeClipboardContentFromMonitorProcessing` clipboard format
- **Linux:** No standard mechanism (continue relying on excluded apps list + secret heuristics)

## Why Deferred

The `arboard` crate (used for clipboard read/write) doesn't expose platform metadata. Detecting these markers requires direct platform API access:

- **macOS:** Objective-C interop via `objc2` / `icrate` to enumerate `NSPasteboard` types
- **Windows:** Win32 `GetClipboardData` / `IsClipboardFormatAvailable` with custom format registration

This is meaningful extra work and adds platform-specific native code beyond what the clipboard kit otherwise needs.

## Phase 1 Mitigation

The clipboard kit ships without concealed marker detection. Privacy is still protected by:
1. **Excluded apps list** — user-configurable, defaults include 1Password, Bitwarden, KeePassXC, LastPass
2. **Secret-like content heuristics** — entropy and pattern matching (with redacted placeholders for visibility)
3. **Retention period** — entries auto-delete after configurable TTL

## Implementation Notes

When implementing, consider:
- Adding concealed checks to the watcher pipeline *before* content is read (if possible — check markers on the pasteboard without reading content)
- On macOS, `NSPasteboard.types` can be enumerated without reading the actual content
- On Windows, `IsClipboardFormatAvailable` is a cheap check
- Concealed entries should be skipped entirely (not even stored as redacted placeholders)
- This should be a `#[cfg]`-gated module with a shared trait interface per cross-platform conventions
