Key Design Decisions

SDK in Main Process

CopilotClient lives in Electron main. No sidecar, no bridging. The SDK spawns and manages the CLI binary internally via JSON-RPC over stdio. We never touch the CLI directly.

Work IQ via SDK MCP

Work IQ MCP server is registered with the Copilot session as an MCP tool source. The agent can call Work IQ tools autonomously when the user asks about meetings/calendar. No separate Work IQ process to manage.

Meeting Polling

Background interval in main process queries upcoming meetings via Copilot + Work IQ every ~15min. Results cached. Notifications fired based on proximity. Cheap enough for personal use; Graph API can replace later.

Overlay Window

Single BrowserWindow: frameless, always-on-top, transparent. Hidden by default, shown on global hotkey. Same pattern as current Flint — just Electron APIs instead of Tauri.
