Meeting Alerts & Overlay UI

Background monitoring, notifications, and the overlay experience

Meeting Monitor — Background Loop
// Runs in Electron main process, always active while app is in tray
 
EVERY 15 MINUTES:
  ├─ Send to background Copilot session:
  │  "List my meetings for the next 3 hours with times, titles, attendees, and join links."
  ├─ Parse structured response → cache as Meeting[] in memory
  └─ Update tray icon badge (number of upcoming meetings)
 
EVERY 60 SECONDS (tick against cache):
  ├─ For each cached meeting:
  │  ├─ If starts in ≤ alertMinutes (default 5) AND not yet alerted:
  │  │  ├─ Fire native OS notification
  │  │  │  ├─ Title: "Meeting in 5 min"
  │  │  │  ├─ Body: "Q4 Planning — with Sarah, Mike, Lisa"
  │  │  │  └─ Action: click → show overlay with meeting context
  │  │  └─ Mark meeting as "alerted" in cache
  │  └─ If started and passed → remove from cache
  └─ If overlay is open → push updated meeting cards to renderer
