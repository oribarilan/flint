NOTES

  • What this explores: How buildSuggestions() output blends with the current Guide empty state across different calendar scenarios.
  • Calendar states: No meetings — pure static defaults (current production behavior). Imminent — "Design Review" in 8 min → contextual "Prepare me for Design Review" card replaces the generic. Busy day — 5 meetings today → "Summarize today's schedule" promoted to position 1. Both — imminent + busy combined.
  • A (Seamless) — Zero visual difference. The text just changes. Pro: no new concepts, no UI complexity. Con: user may not notice the suggestions are personalized.
  • B (Tinted) — Subtle accent wash on contextual cards. Pro: user sees "this is about me right now" without it being loud. Con: adds visual weight, could feel promotional.
  • C (Sectioned) — Explicit grouping: "Right now" and "Or try". Pro: very clear what's contextual vs generic, works well when you have 2+ contextual cards. Con: heavier, more chrome, may feel over-structured for 1 card.
  • Fidelity gap: DM Sans font not loaded — using system fallback. Emoji icons instead of Lucide SVGs.
  • Critical path preserved: All variants read from existing renderer state. buildSuggestions(items) is a pure function — no IPC, no network, no disk I/O.
