Markdown Bold/Italic Rendering

Comparing how **bold** and *italic* render in assistant chat messages. Headers, lists, code, and links are identical across all variants.

A. Traditional Baseline
Bold = font-weight 600. Italic = font-style italic. Standard typographic rendering.
B. Accent Colors
Bold = amber accent color (no weight change). Italic = warm elevated white (no style change). Pure color differentiation.
C. Warm Tints
Bold = bright warm white (L97%, slight chroma) + weight 500. Italic = muted warm tone (L72%, more chroma). Subtle, ambient.
D. Hybrid
Bold = weight 600 + accent color. Italic = italic style + warm elevated tint. Combines weight, style, and color signals.

Design Notes

Headers, lists, code blocks, and links are styled identically across all four variants. Only strong and em rendering differs.

All colors use OKLCH and sit within Flint's warm-tinted neutral palette (hue 60-65). No pure grays.

User messages (amber bubbles) are always plain text with no markdown rendering.
